# Support

Tablet Workdesk is maintained as a small open-source project.

## Before Opening An Issue

Please check:

- [Install](docs/INSTALL.md)
- [Troubleshooting](docs/TROUBLESHOOTING.md)
- [Device compatibility](docs/DEVICE_COMPATIBILITY.md)

## Good Bug Reports Include

- Android version.
- Device model and RAM.
- Termux source and version.
- Client app: AVNC, Chrome/noVNC, direct VNC, or another VNC viewer.
- The command that failed.
- Relevant logs from `~/tablet-workdesk/logs`.

## Security Reports

For security issues, see [SECURITY.md](SECURITY.md).
