# Roadmap

Tablet Workdesk is an early public project. The roadmap is intentionally small
and focused on reliability.

## v0.1.x

- Document install and troubleshooting paths.
- Add device report issue template.
- Add local repository validation scripts.
- Add initial release notes and security docs.
- Collect first public compatibility reports.

## v0.2.x

- Add a minimal install profile without LibreOffice or Firefox ESR.
- Add a tested low-RAM profile.
- Add safer update and rollback behavior.
- Add screenshots and short demo media.
- Add a documented uninstall command.

## v0.3.x

- Add pinned upstream component versions for reproducible installs.
- Add device profile selection.
- Add better diagnostics for VNC, noVNC, AVNC, locale, and input-method issues.
- Add release asset packaging for the Termux installer.

## Non-Goals

- Replacing Termux, Debian, TigerVNC, noVNC, or AVNC.
- Exposing VNC/noVNC to public networks by default.
- Optimizing for gaming or GPU-heavy desktop workloads.
- Supporting Google Play Termux as a primary target.
