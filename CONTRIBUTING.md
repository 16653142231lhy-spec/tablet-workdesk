# Contributing

Contributions are welcome, especially fixes that make the workflow more
reliable on low-cost Android tablets.

Useful contributions include:

- Tested device notes: Android version, RAM, Termux source, client app, and what
  worked or failed.
- Installer fixes for package changes in Termux or Debian.
- Lower-memory profiles for older devices.
- Troubleshooting notes for input, locale, VNC, noVNC, and AVNC issues.
- Security improvements around local service binding and authentication.

Please avoid posting private device data, tokens, personal documents, or logs
that contain account information.

For larger changes, open an issue first with:

- The problem.
- The device and environment.
- The command you ran.
- The relevant log excerpt.
- The expected behavior.
